O PROCESSO

Poucas perguntas.
Um ponto de partida real.

A primeira execução prepara o contexto. O aprofundamento acontece depois, quando cada decisão for necessária.

01

Descreva o projeto

Informe nome, tipo, organização e capacidades. Perguntas aparecem conforme as respostas anteriores.

02

Revise o plano

Veja as respostas e os arquivos previstos. Use --dry-run para inspecionar sem escrever nada.

03

Evolua com clareza

Edite os documentos gerados. Decisões pendentes ficam explícitas para pessoas e agentes retomarem no momento certo.

PRONTO PARA COMEÇAR?

Do terminal ao contexto em dois comandos.

Use Node.js 24 ou superior. Entre no diretório do projeto que receberá os documentos: a CLI escreve ali e não cria outra pasta.

terminal

# Primeiro, revise sem criar arquivos

$ npx project-spec-starter@1.0.0 init --dry-run

# Depois, gere os documentos

$ npx project-spec-starter@1.0.0 init
✓ Arquivos existentes são preservados.
